Projects

Cloud Portfolio CMS

Designed and deployed a production-style portfolio CMS on AWS using Terraform for Infrastructure as Code. The architecture runs a Flask application on EC2 instances in private subnets behind an Application Load Balancer and Auto Scaling Group, with PostgreSQL on Amazon RDS. Built REST API endpoints that dynamically deliver projects, certifications, contact information, and resume data to a static S3/CloudFront frontend. Implemented Route 53 DNS, ACM HTTPS, IAM roles, Secrets Manager, S3-backed file storage, health checks, automated EC2 bootstrapping, and persistent database backups.

Tech: AWS, Terraform, Python, Flask, PostgreSQL, EC2, Auto Scaling, ALB, RDS, S3, CloudFront, Route 53, ACM, IAM, Secrets Manager
